# Reviewed LobeHub pull-request artwork

The mainline catalogue from https://icons.lobehub.com/ is pinned in
[sources/lobehub.json](../sources/lobehub.json). Additional reviewed contributions
are pinned separately in [sources/lobehub-prs.json](../sources/lobehub-prs.json),
which records their PR links, review state, artwork, exports and exact revisions.
Inclusion here does not imply upstream acceptance. New contributions receive a
source review and visual inspection before import.

When a contribution merges upstream, move its artwork to mainline provenance and
remove the duplicate PR snapshot. Preserve its published IDs, variants and React
exports even when upstream uses different capitalization or display names.

PR [#391](https://github.com/lobehub/lobe-icons/pull/391) also corrects the
HappyHorse display name, previously copied as “Hedra”. Existing SVG asset bytes
remain unchanged; the catalogue supplies the corrected name. `5dive` resolves
to the canonical `fivedive` icon.

The visual review also corrected two wordmarks from PR #375. Deyin's paths
occupy only x=18.25–29, y=5–8.978 in an original 30×24 viewBox, making the text
tiny and off-centre. The exported viewBox is cropped to `18 4.75 11.25 4.5`.
Openference's wordmark glyphs use an upward y-axis; a
`translate(0 24) scale(1 -1)` group restores their upright orientation.
Both corrections retain the original paths and are recorded in the snapshot's
`adjustments` with reasons and matching original source hashes.

PersonaStack’s Text component uses platform fonts and hardcoded text positions.
It is deliberately omitted until an outlined vector wordmark is available.
Its monochrome and colour icons are included. OrcaRouter’s source Text paths
render an incorrect wordmark with misplaced, overlapping glyphs, so its wordmark
is also omitted pending a corrected outline; its two icons remain included.
Avatar and Combine are generated by this library wherever the corresponding artwork exists; upstream React
wrappers and unrelated application logic are not imported.

Source artwork retains its original design choices. Modelflare's colour icon
uses a fixed dark outline; use its monochrome variant with a contrasting foreground
on dark surfaces. WorkBuddy's partial mascot silhouette and stacked wordmark
are intentional upstream geometry, not missing paths in the import.

## Reproduction

Each record in `sources/lobehub-prs.json` includes an immutable head SHA, source
contents, SHA-256 and Git blob hashes, and the source files used for each SVG.
Existing static SVGs are preferred when the PR provides them. Otherwise the
TypeScript AST reader handles literal JSX, literal constants and local gradient
IDs without importing or executing upstream code. The normal SVG allowlist is
then applied. Unknown expressions and SVG features fail for review.

```sh
npm ci --ignore-scripts
npm run sync:lobehub-prs       # offline replay of the pinned snapshots
npm run build
npm test                     # checks reproducibility and source/asset hashes
```

To add an explicitly reviewed PR:

```sh
npm run sync:lobehub-prs -- --add-pr 454
npm run sync:discovery
npm run build
npm test
```

The fetch uses GitHub CLI authentication and raw files pinned to the head SHA.
It does not install PR packages or run upstream scripts. Review the resulting
source and artwork diff before publishing. Record an intentional omission with
`--omit NUMBER:PATH=REASON`; an omission never substitutes guessed artwork.

If a contribution later appears in the mainline catalogue, either sync command
stops on the duplicate. Reconcile that icon’s source and provenance explicitly
before switching to the merged artwork, preserving published IDs and variants.
Consumer galleries enumerate the generated manifest, so these additions require
no per-icon application code.
