occupy only x=18.25–29, y=5–8.978 in an original 30×24 viewBox, making the text

`adjustments` with reasons and matching original source hashes.

## Reproduction

Each record in `sources/lobehub-prs.json` includes an immutable head SHA, source
contents, SHA-256 and Git blob hashes, and the source files used for each SVG.
Existing static SVGs are preferred when the PR provides them. Otherwise the
TypeScript AST reader handles literal JSX, literal constants and local gradient
IDs without importing or executing upstream code. The normal SVG allowlist is
then applied. Unknown expressions and SVG features fail for review.

```sh
npm ci --ignore-scripts
npm run sync:lobehub-prs       # offline replay of the pinned snapshots
npm run build
npm test                     # checks reproducibility and source/asset hashes
```

To add an explicitly reviewed PR:

```sh
npm run sync:lobehub-prs -- --add-pr 425
npm run sync:discovery
npm run build
npm test
```

The fetch uses GitHub CLI authentication and raw files pinned to the head SHA.
It does not install PR packages or run upstream scripts. Review the resulting
source and artwork diff before publishing. Record an intentional omission with
`--omit NUMBER:PATH=REASON`; an omission never substitutes guessed artwork.

If a contribution later appears in the mainline catalogue, either sync command
stops on the duplicate. Reconcile that icon’s source and provenance explicitly
before switching to the merged artwork, preserving published IDs and variants.
Consumer galleries enumerate the generated manifest, so these additions require
no per-icon application code.
